## Overview

**ElderAid** is a historical web interface prototype exploring how information about assistance, services, and community support could be presented in a simple landing-page experience.

The prototype contains sections related to informational resources, benefits, donations, and navigation to an account interface. It is a **frontend concept**, not a verified live assistance platform.

## Main interface sections

| Section | What it demonstrates |
|:--|:--|
| Landing page | Introductory message and calls to action |
| Information | Example educational and benefits information |
| Support | Donation-oriented content and service discovery concepts |
| Account screen | Sign-in / sign-up UI transitions |

## Technology

HTML, CSS, JavaScript, jQuery, and Bootstrap-style frontend assets. No production backend or live benefit-eligibility integration is verified.

## Explore the code

- [`index.html`](index.html) — primary landing page
- [`join.html`](join.html) — user account interface
- [`app.js`](app.js) — sign-in/sign-up UI interaction
- [`css/`](css/) — styles
- [`img/`](img/) — interface media

To inspect locally, clone the repository and open `index.html` in your browser. External forms, images, and services may have changed since the prototype was created.

## Project scope

This repository is retained as an example of early frontend and human-centered interface experimentation. It does not provide legal advice, benefits determinations, donations processing, or verified access to public assistance services.
